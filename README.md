# OceanViewResort-Reservation-System
The Ocean View Resort Reservation System is a Java-based application designed to automate hotel room reservations, replacing manual booking processes to improve efficiency and reduce errors. It features secure user authentication and allows staff to add, manage, and view reservations with guest details, room types, and check-in/check-out dates. The front end is built using HTML, CSS, and JavaScript, while the backend uses Java/Java EE with a MySQL database for secure data storage. Version control is managed through Git and GitHub, and the system follows best practices such as modular design, input validation, and exception handling, making it scalable, maintainable, and easily extendable with features like billing and reporting.
