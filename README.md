# OceanViewResort-Reservation-System
The Ocean View Resort Reservation System is a Java-based application that automates hotel reservations. The front end uses HTML and CSS, the backend uses Java/Java EE, and MySQL stores data securely. Version control is handled via GitHub.
The Ocean View Resort Reservation System is a Java-based application that automates hotel room reservations, replacing manual booking processes to improve efficiency and reduce errors. It provides secure user authentication and allows staff to add, manage, and view reservations with details such as guest information, room type, and check-in/out dates.

The front end is developed using HTML, CSS, and JavaScript, while the backend uses Java/Java EE . A MySQL database stores reservation data securely.

Version control is maintained through Git and GitHub, enabling systematic tracking of changes, feature updates, and project history.

The system follows best practices including modular design, input validation, and exception handling. It is scalable, maintainable, and can be extended with features like billing, reporting, and web-based access, providing a reliable and efficient solution for hotel management.
